# Bank Statement Analyzer

AI-powered bank statement analysis platform developed as part of an internship project.

## Features

- PDF and Excel statement upload
- Multi-statement analysis
- Automated categorization
- Spending analytics dashboard
- Financial forecasting
- Insight generation
- PDF report generation

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## Installation

pip install -r requirements.txt 
python app.py
